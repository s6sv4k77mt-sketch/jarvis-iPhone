# J.A.R.V.I.S.

Assistente AI in stile Tony Stark: sfera futuristica rotante, voce maschile in italiano, ricerca web, meteo e ora di Bologna, ricorda il tuo compleanno.

## Avvio

1. Installa Node.js 18 o superiore.
2. Copia `.env.example` in `.env` e inserisci la tua chiave API Anthropic.
3. Esegui `npm install` e poi `npm start`.
4. Apri http://localhost:3000 con Chrome o Edge e tocca la sfera.
